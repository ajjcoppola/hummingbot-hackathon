# Portal clicks (Botcamp, not Devpost)

1. https://www.botcamp.xyz/hackathons/agent-builders-cup-1 → Register / Sign up
2. Apply to race for **Orca** (team page has "Apply to Race")
3. Dashboard → My Strategies → New Strategy
4. Paste `APPLICATION.md` fields
5. Save, then upload Code Files and Video Link
6. Confirm the strategy is tied to the hackathon application and is **submitted**

If a field is optional, still fill Description + Markets + Parameters + Events. Judges read those.
